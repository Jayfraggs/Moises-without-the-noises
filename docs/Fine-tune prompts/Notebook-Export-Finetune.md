

### [NOTEBOOK-EXPORT-01] Notebook Generator — Backend

**Target Files:** `backend/jobs/notebook_generator.py` *(new)*

**Context:** When the user configures their extraction settings in the extract panel and clicks "Run Selected", instead of (or in addition to) queuing a job, the backend generates a customised `.ipynb` file with their settings pre-injected into the parameters cell. The notebook is returned as a file download. This replaces the static `colab/mwtn_notebook.ipynb` as the thing the user actually runs — the static one becomes a template only.

**Objective:**
Implement `generate_notebook(settings: NotebookSettings) -> bytes` that takes the user's extract panel settings, injects them into the parameters cell of the template notebook, and returns the serialised `.ipynb` as bytes.

**Technical Specifications:**

**`NotebookSettings` dataclass:**
```python
@dataclass
class NotebookSettings:
    # Identity
    job_id: str               # pre-generated UUID so the notebook knows its job
    song_title: str
    backend_url: str          # injected so Colab can report back — user fills this in Colab

    # Source
    source_url: str = ""      # YouTube URL if provided at queue time
    source_path: str = ""     # empty for Colab path (file uploaded in Colab instead)

    # Separation
    demucs_model: str = "htdemucs_6s"
    stems: list[str] = field(default_factory=lambda: ["vocals","bass","guitar","piano","drums","other"])

    # Transcription
    enable_whisper: bool = True
    whisper_model: str = "small"
    whisper_language: str = "auto"
    enable_alignment: bool = True

    # Notes
    enable_notes: bool = True
    note_confidence: float = 0.6
    note_min_dur: float = 0.1

    # Chords
    enable_chords: bool = True

    # Score
    enable_solfa: bool = True
    solfa_system: str = "movable_do"
    solfa_minor: str = "la_based"
    quantize_grid: int = 16
    enable_beaming: bool = True

    # Confidence
    enable_confidence: bool = True
    confidence_threshold: float = 0.15

    # Export
    enable_midi: bool = True
    enable_musicxml: bool = True
    enable_click_track: bool = True
```

**`generate_notebook` logic:**
```python
import json
from pathlib import Path
from copy import deepcopy

TEMPLATE_PATH = Path("colab/mwtn_notebook.ipynb")

def generate_notebook(settings: NotebookSettings) -> bytes:
    template = json.loads(TEMPLATE_PATH.read_text(encoding="utf-8"))
    notebook = deepcopy(template)

    # Find the parameters cell (tagged 'parameters')
    params_cell = _find_params_cell(notebook)
    if params_cell is None:
        raise ValueError("Template notebook has no cell tagged 'parameters'")

    # Replace its source with injected values
    params_cell["source"] = _render_params_cell(settings)

    return json.dumps(notebook, indent=1, ensure_ascii=False).encode("utf-8")


def _find_params_cell(notebook: dict) -> dict | None:
    for cell in notebook.get("cells", []):
        tags = cell.get("metadata", {}).get("tags", [])
        if "parameters" in tags:
            return cell
    return None


def _render_params_cell(s: NotebookSettings) -> list[str]:
    """Returns a list of source lines for the parameters cell."""
    lines = [
        "# ═══════════════════════════════════════════════════════\n",
        "# MWTN — Auto-generated parameters. Do not edit manually.\n",
        "# Generated by MWTN extract panel. Re-generate to change.\n",
        "# ═══════════════════════════════════════════════════════\n",
        "\n",
        f'JOB_ID        = "{s.job_id}"\n',
        f'SONG_TITLE    = "{s.song_title}"\n',
        f'BACKEND_URL   = ""  # ← Paste your ngrok URL here before running\n',
        f'SOURCE_URL    = "{s.source_url}"\n',
        f'SOURCE_PATH   = "{s.source_path}"\n',
        "\n",
        f'DEMUCS_MODEL  = "{s.demucs_model}"\n',
        f'STEMS         = {json.dumps(s.stems)}\n',
        "\n",
        f'ENABLE_WHISPER    = {str(s.enable_whisper)}\n',
        f'WHISPER_MODEL     = "{s.whisper_model}"\n',
        f'WHISPER_LANGUAGE  = "{s.whisper_language}"\n',
        f'ENABLE_ALIGNMENT  = {str(s.enable_alignment)}\n',
        "\n",
        f'ENABLE_NOTES      = {str(s.enable_notes)}\n',
        f'NOTE_CONFIDENCE   = {s.note_confidence}\n',
        f'NOTE_MIN_DUR      = {s.note_min_dur}\n',
        f'ENABLE_CHORDS     = {str(s.enable_chords)}\n',
        "\n",
        f'ENABLE_SOLFA      = {str(s.enable_solfa)}\n',
        f'SOLFA_SYSTEM      = "{s.solfa_system}"\n',
        f'SOLFA_MINOR       = "{s.solfa_minor}"\n',
        f'QUANTIZE_GRID     = {s.quantize_grid}\n',
        f'ENABLE_BEAMING    = {str(s.enable_beaming)}\n',
        "\n",
        f'ENABLE_CONFIDENCE      = {str(s.enable_confidence)}\n',
        f'CONFIDENCE_THRESHOLD   = {s.confidence_threshold}\n',
        "\n",
        f'ENABLE_MIDI        = {str(s.enable_midi)}\n',
        f'ENABLE_MUSICXML    = {str(s.enable_musicxml)}\n',
        f'ENABLE_CLICK_TRACK = {str(s.enable_click_track)}\n',
    ]
    return lines
```

**Execution Constraints:**
- Never mutate `TEMPLATE_PATH` — always `deepcopy` before editing.
- If `_find_params_cell` returns `None`: raise `ValueError` — do not silently inject into the wrong cell.
- All string values must be JSON-safe — run through `json.dumps(value)` for any user-supplied string (song title, URL) to escape quotes and special characters.
- `BACKEND_URL` is always left blank in the generated notebook with a comment — the user must fill it in themselves in Colab. Do not pre-fill it from the backend's own URL (that would be localhost, which Colab can't reach).

**Output Request:**
Return only `backend/jobs/notebook_generator.py`.

### [NOTEBOOK-EXPORT-BE-02] Notebook Download + Clipboard API Routes

**Target Files:** `backend/main.py` *(add routes)*

**Objective:**
Add two routes: one that generates and returns the notebook as a file download, and one that returns the parameters cell source as plain text (for clipboard copy).

**Technical Specifications:**

**`POST /api/jobs/generate-notebook`:**

Request body:
```json
{
  "song_title": "Fela Kuti — Zombie",
  "source_url": "https://www.youtube.com/watch?v=...",
  "settings": {
    "demucs_model": "htdemucs_6s",
    "enable_whisper": true,
    "whisper_model": "small",
    ...
  }
}
```

- Generates a `job_id` (UUID4) and creates a `queued` job entry in the job store — so the job exists and can receive PATCH updates when Colab runs.
- Calls `generate_notebook(settings)`.
- Returns the `.ipynb` file as a download:
  - `Content-Type: application/x-ipynb+json`
  - `Content-Disposition: attachment; filename="mwtn_{song_title_slug}_{job_id[:8]}.ipynb"`
- Also returns the `job_id` in a response header: `X-MWTN-Job-ID: {job_id}` — the frontend reads this to start polling the job.

**`POST /api/jobs/generate-params-text`:**

Same request body as above. Returns:
```json
{
  "job_id": "...",
  "params_text": "JOB_ID = \"...\"\nSONG_TITLE = ...\n...",
  "instructions": {
    "colab": [
      "Open colab/mwtn_notebook.ipynb in Google Colab.",
      "Find the cell tagged 'parameters' (it has a yellow border in Colab).",
      "Select all text in that cell and paste the copied parameters.",
      "Fill in your BACKEND_URL (ngrok URL) in that cell.",
      "Run all cells from top to bottom (Runtime → Run all)."
    ],
    "local": [
      "Papermill will run the notebook automatically.",
      "Trigger via: POST /api/jobs/{job_id}/run-local",
      "Or use the 'Run Locally' button in the app."
    ]
  }
}
```

**Execution Constraints:**
- Both routes create the job in the store before returning — the `job_id` is live immediately.
- `song_title_slug`: lowercase, spaces to hyphens, strip non-alphanumeric except hyphens. Max 40 chars.
- Wrap file generation in `asyncio.to_thread` — reading the template file is I/O.
- Structured error JSON on failure (template missing, malformed settings, etc.).

**Output Request:**
Return only the two new route blocks for `main.py`.

**Job polling + tracker rendering:**

```js
function _startPolling(jobId) {
  const { stop } = pollJob(jobId, (job) => {
    _updateTracker(job);
    if (['done','failed','cancelled'].includes(job.status)) {
      stop();
      if (job.status === 'done') _showDone(job);
      if (job.status === 'failed') _showFailed(job);
    }
  }, 3000);
  _stopCurrentPoll = stop;
}

function _updateTracker(job) {
  document.getElementById('run-tracker').hidden = false;

  const STEP_LABELS = {
    downloading:  '⬇ Downloading audio',
    separating:   '≋ Separating stems',
    transcribing: 'T Transcribing lyrics',
    analysing:    'A Analysing (beats, key, notes, solfa)',
    packaging:    '📦 Packaging and uploading',
  };

  const container = document.getElementById('tracker-steps');
  container.innerHTML = '';
  for (const step of job.steps) {
    const row = document.createElement('div');
    row.className = `tracker-step tracker-step--${step.status}`;
    row.innerHTML = `
      <span class="tracker-step-icon">${_stepIcon(step.status)}</span>
      <span class="tracker-step-name">${STEP_LABELS[step.name] ?? step.name}</span>
      ${step.progress_pct != null
        ? `<span class="tracker-step-pct">${Math.round(step.progress_pct)}%</span>`
        : ''}
      ${step.status === 'failed'
        ? `<span class="tracker-step-error">${step.error ?? ''}</span>`
        : ''}
    `;
    container.appendChild(row);
  }

  document.getElementById('tracker-status-label').textContent =
    _statusLabel(job.status);
  document.getElementById('tracker-eta').textContent =
    job.estimated_duration_s ? `~${Math.round(job.estimated_duration_s / 60)} min` : '';
}

function _stepIcon(status) {
  return { pending:'○', running:'◉', done:'✓', failed:'✕', skipped:'–' }[status] ?? '?';
}

function _showDone(job) {
  document.getElementById('tracker-status-label').textContent = '✓ Done — song is ready';
  const loadBtn = document.createElement('button');
  loadBtn.className = 'run-action-btn run-action-btn--primary';
  loadBtn.textContent = '▶ Load Song';
  loadBtn.addEventListener('click', () => {
    store.set({ pendingSongId: job.song_id });
    closeRunPanel();
  });
  document.getElementById('run-tracker').appendChild(loadBtn);
}

function _showFailed(job) {
  document.getElementById('tracker-status-label').textContent =
    `✕ Failed: ${job.error_message ?? 'Unknown error'}`;
  document.getElementById('tracker-status-label').style.color = '#f87171';
}
```

**Clipboard fallback (for browsers without `navigator.clipboard`):**
```js
async function _copyToClipboard(text) {
  if (navigator.clipboard?.writeText) {
    await navigator.clipboard.writeText(text);
    return;
  }
  // Fallback: textarea trick
  const ta = document.createElement('textarea');
  ta.value = text;
  ta.style.position = 'fixed';
  ta.style.opacity = '0';
  document.body.appendChild(ta);
  ta.focus();
  ta.select();
  document.execCommand('copy');
  document.body.removeChild(ta);
}
```

// Returns blob + job_id from response header
export async function downloadNotebook(songTitle, sourceUrl, settings) {
  const res = await fetch('/api/jobs/generate-notebook', {
    method: 'POST',
    headers: { 'Content-Type': 'application/json' },
    body: JSON.stringify({ song_title: songTitle, source_url: sourceUrl, settings }),
  });
  if (!res.ok) {
    const err = await res.json().catch(() => ({}));
    throw new Error(err.detail ?? `HTTP ${res.status}`);
  }
  const jobId = res.headers.get('X-MWTN-Job-ID');
  const blob = await res.blob();
  return { blob, jobId };
}

// Returns { job_id, params_text, instructions }
export async function generateParamsText(songTitle, sourceUrl, settings) {
  const res = await fetch('/api/jobs/generate-params-text', {
    method: 'POST',
    headers: { 'Content-Type': 'application/json' },
    body: JSON.stringify({ song_title: songTitle, source_url: sourceUrl, settings }),
  });
  if (!res.ok) {
    const err = await res.json().catch(() => ({}));
    throw new Error(err.detail ?? `HTTP ${res.status}`);
  }
  return res.json();
}

## Running a Generated Notebook

The MWTN extract panel generates a customised notebook with your settings 
pre-filled. This is the recommended way to run Colab — you never edit the

### Three ways to run

#### Option A — Download and upload (recommended for first-timers)
1. Configure your settings in the extract panel.
2. Enter your song title and click **Run Selected →**.
3. Click **Download Notebook (.ipynb)**.
4. Go to [colab.research.google.com](https://colab.research.google.com).
5. File → Upload notebook → select the downloaded file.
6. Find the **Parameters cell** (yellow border, near the top).
7. Fill in `BACKEND_URL` with your ngrok URL.
8. Runtime → Run all.
9. Return to MWTN — the status tracker updates automatically.

#### Option B — Copy parameters (if you already have the notebook open)
1. Click **Run Selected →** in the extract panel.
2. Click **Copy Parameters**.
3. In your open Colab notebook, click into the Parameters cell.
4. Select all (Ctrl+A / Cmd+A) and paste.
5. Fill in `BACKEND_URL`.
6. Runtime → Run all.

#### Option C — Run locally (no Colab, no internet)
1. Click **Run Selected →** in the extract panel.
2. Click **Run Locally via Papermill**.
3. The notebook runs on your machine. Expect 30–90 minutes on CPU.
4. No ngrok URL needed — the backend is local.

...
​```

**You only need to fill in `BACKEND_URL`** — everything else is pre-configured
