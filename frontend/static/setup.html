How will you process songs?

mwtn separates songs into stems (vocals, drums, bass, guitar…). Choose where that heavy ML work runs.

⚠ Mobile data warning: The local path downloads ~2.3 GB of Demucs model weights on first use. Run the local setup on Wi-Fi.
What Colab does: Opens a free GPU notebook in your browser. You run it once per song — it handles Demucs, Whisper transcription, BPM and key detection. The output ZIP drops into your Google Drive (or you download it) and you drag it into mwtn.

Configure Colab path

Tell mwtn where to find your Google Drive output folder so it can auto-import new songs.

This is the top-level Google Drive folder on your computer (via Drive for Desktop). On Windows it's usually G:\My Drive or H:\My Drive. On Mac: /Users/you/Library/CloudStorage/GoogleDrive-you@gmail.com/My Drive
Must match DRIVE_OUTPUT_FOLDER in Cell 3 of the Colab notebook. Default: mwtn-outputs
mwtn will look for output ZIPs at: H:\My Drive\mwtn-outputs
First-run download: ~2.3 GB. Run on Wi-Fi.
Requirements: Python 3.10+, torch, demucs, ffmpeg.
The activate.ps1 / activate.sh script installs everything. Run it before using local import.

Add your first song

Choose how to get a song into mwtn.

  1. 1
    Open the Colab notebook
    Runtime → Change runtime type → T4 GPU (free)
    Open mwtn_notebook.ipynb in Colab
  2. 2
    Run Cell 3 → set your song file path in Cell 4
    Upload your mp3/wav to Google Drive, set DRIVE_FILE_PATH
  3. 3
    Run all cells
    Takes ~2 min on T4 GPU. Output ZIP goes to Google Drive automatically.
  4. 4
    Drop the ZIP into mwtn
    Download it from Drive and drag it into the mwtn window, or use Settings → Scan Drive.
⚠ Data cost: The Colab notebook downloads ~3.5 GB of model weights (Demucs + Whisper) on its first run in a new session. Do this on Wi-Fi. Subsequent runs in the same session cost nothing extra.
How to import a song locally:
Click the Import button in the top-right of the mwtn window and drop an audio file (mp3, wav, flac, m4a). The backend runs Demucs on your machine — expect 10–40 minutes on CPU.
⚠ First-run: Demucs downloads ~2.3 GB of model weights. Run on Wi-Fi.
