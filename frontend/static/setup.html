How will you process songs?

mwtn separates songs into stems (vocals, drums, bass, guitar…). Choose where that heavy ML work runs.

⚠ Mobile data warning: The local path downloads model weights (varies per engine, ~400 MB – 2.3 GB) on first use. Do this on Wi-Fi.
What Colab does: Opens a free GPU notebook in your browser. You run it once per song — it handles separation, Whisper transcription, BPM and key detection. The output ZIP goes to your Google Drive and you drag it into mwtn.

Configure Colab path

Tell mwtn where to find your Google Drive output folder so it can auto-import new songs.

Top-level Google Drive folder on your machine (via Drive for Desktop). Windows: G:\My Drive. Mac: /Users/you/Library/CloudStorage/GoogleDrive-…/My Drive
Must match DRIVE_OUTPUT_FOLDER in Cell 3 of the Colab notebook.
mwtn will look for output ZIPs at: H:\My Drive\mwtn-outputs
Downloaded on first use. Choose base unless you have storage and time to spare. Skip if you don't need lyrics.
⚠ Mobile data: Model weights download on first use. See sizes above. Use Wi-Fi.

Separation engine

On the Colab path, Demucs runs on Google's GPU — nothing to install on your machine. The notebook handles everything.

The default notebook uses htdemucs_6s (6 stems: vocals, drums, bass, guitar, piano, other). You can switch models in Colab Cell 3.
⚠ Colab data cost: The notebook downloads ~3.5 GB of model weights (Demucs + Whisper) on its first run in a new session. Always do this on Wi-Fi.

Install a separation engine

Choose at least one. The installer runs pip install in the background — you can see progress below. You only need one engine to get started.

Add your first song

Choose how to get a song into mwtn.

  1. 1
    Open the Colab notebook
    Runtime → Change runtime type → T4 GPU (free tier)
    Open mwtn_notebook.ipynb in Colab
  2. 2
    Set your song file path in Cell 4
    Upload your mp3/wav to Google Drive, then set DRIVE_FILE_PATH
  3. 3
    Run all cells
    Takes ~2 min on T4 GPU. Output ZIP goes to Google Drive automatically.
  4. 4
    Drop the ZIP into mwtn
    Download from Drive and drag it into the mwtn window, or use Settings → Scan Drive.
⚠ Colab first-run data cost: Downloads ~3.5 GB (Demucs + Whisper model weights) on first session. Always do this on Wi-Fi.
How to import a song locally:
Click the Import button (top bar) or drag an audio file (mp3, wav, flac, m4a) onto the mwtn window. The backend runs the separation engine you installed — expect 10–40 min on CPU.
⚠ First-run: The engine downloads model weights on its first separation. Run on Wi-Fi.
